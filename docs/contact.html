Responsible use

Purple Sparrow is alpha software and its policy engine has not yet had an independent security audit. Don't put regulated or sensitive personal data behind it in production until you've reviewed it for your own threat model. Deny-by-default helps, but you own the policies you write and the deployment you run.

Status

Built and tested: foundations, data + policy engine, auth, the agent layer, MCP/CLI, and a Postgres engine. Planned: storage, edge functions, realtime, and a dashboard. The repo's README tracks the current state honestly.
