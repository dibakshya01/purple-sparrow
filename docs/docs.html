Quick start

Go 1.27+. Everything below runs against the single binary with embedded SQLite — no external services.

1 · Build & run

# one static binary, embedded SQLite
CGO_ENABLED=0 go build -o orangecrow ./cmd/orangecrow
OC_ADMIN_API_KEY=oc_sk_dev ./orangecrow   # → 127.0.0.1:8787

2 · Create a table

id (uuid) and created_at are added automatically. Types: text, integer, real, boolean, timestamp, uuid, json.

curl -H "Authorization: Bearer oc_sk_dev" localhost:8787/v1/tables -d '{
  "name": "todos",
  "columns": [{"name":"title","type":"text"},
              {"name":"owner_id","type":"text"}] }'

3 · Grant access (deny-by-default)

Nothing is readable until a policy says so. Policies compile to parameterized SQL and support using (which rows) and check (allowed new values).

curl -H "Authorization: Bearer oc_sk_dev" localhost:8787/v1/policies -d '{
  "table": "todos", "action": "select",
  "roles": ["authenticated"],
  "using": "auth.uid() = owner_id" }'

4 · Records

POST   /v1/tables/todos/records            # insert (object or array)
GET    /v1/tables/todos/records?done=eq.false&order=created_at.desc&limit=20
GET    /v1/tables/todos/records/{id}
PATCH  /v1/tables/todos/records/{id}
DELETE /v1/tables/todos/records/{id}

Filters are ?column=op.value with op in eq, ne, lt, lte, gt, gte, like, in.

CLI

orangecrow            # serve (default)
orangecrow mcp        # MCP stdio server for coding agents
orangecrow mcp-config # print an MCP client config snippet
orangecrow version

Connect an agent (MCP)

Run orangecrow mcp-config and drop the snippet into your agent's MCP config (Cursor, Claude, …). It launches orangecrow mcp, which exposes the backend as tools: fetch_docs, get_meta, list_tables, create_table, query_records, insert_record, create_policy, run_advisor.
