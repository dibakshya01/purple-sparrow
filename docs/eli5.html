In plain English

For people who don't write code.

Software products need a "back office" — a place to store data (users, orders, messages), check who's allowed to see what, and run logic. That back office is called a backend. Orange Crow is a backend built for a new kind of worker: the AI coding assistant.

The analogy

Imagine hiring a brilliant, fast new employee who can build whole features by themselves — but they're brand new and can only communicate by filling out forms. A normal back office assumes a human is clicking around, so this employee keeps making mistakes no one catches, and can't easily ask "what's in here?"

Orange Crow is a back office designed for that employee. When they make a mistake, the form it hands back says exactly how to fix it. There's a single page that lists everything the office contains. And by default, every drawer is locked until someone writes a rule that opens it — so sensitive data isn't left exposed by accident.

What it is

An open-source backend (database + security rules + tools) that an AI coding assistant can operate correctly and safely.

Why it matters

Teams are shipping with AI assistants. This reduces the two big risks: data left exposed, and the assistant getting stuck.

How it's run

A single program. A developer starts it with one command on a laptop; it scales to the cloud without a rewrite.

Honest about limits

This is an early (alpha) project. It's real, tested, and safe to try — but not yet battle-tested in production, and some planned pieces aren't built yet.

  • Built today: database, security policies, logins, the agent tools, and the single-binary + Postgres options.
  • Not yet built: file storage, serverless functions, live updates, and the visual admin screen.
  • Before storing real customer data, it should get an independent security review.

Talking points for leaders

  • Security posture: "deny-by-default" means nothing is readable until a rule explicitly allows it — the safe default.
  • No lock-in: open source (Apache-2.0), standard technologies, runs on your own infrastructure.
  • Cost/ops: one small program; a beginner can run it for free locally, and it grows to a normal database for scale.
  • Future-fit: designed around the way AI coding tools actually work, not retrofitted onto a human dashboard.
